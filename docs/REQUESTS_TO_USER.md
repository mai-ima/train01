## B. 方針の確認(1回だけお答えください)
1. **品質の到達目標の現実性**: 現在の方式(Python でプリミティブから組み立てる手続き型モデリング)では、独立監査で外観約55点・車内約45点です(合格は95/90)。**実写と見分けがつかない水準(95点)に届くには、手作業の高精細モデル(ZBrush/Blender 手彫り)か、写真・AI 生成メッシュの取り込みが必要**だと考えます。次のどれで進めますか。
   - (a) このまま手続き型で可能な限り上げる(到達はおそらく70〜80点程度)
   - (b) 車両・人物など主要部品だけ、外部で作った高精細モデル(.blend/.fbx/.glb)を取り込む(ご提供または有償素材)
   - (c) AI(画像/メッシュ生成)を併用する(ローカル GPU が必要。当環境は CPU のみ)
2. **レンダ速度と品質**: 現在 1枚あたり数分(CPU 4コア)。解像度/サンプルを上げる最終レンダ(1600〜1920px・128サンプル以上)は1枚10〜30分かかります。最終納品の解像度はどれにしますか(1600/1920/2560)。
3. **GitHub**: `mai-ima/train01` に節目ごとにまとめてコミットする運用にします(1作業ごとはやめます)。OK ですか。
