# 監査基準(audit_rubric.md) — 超高品質・差別化
合格は次の2条件を**両方**満たすときだけ。それ以外は不合格(修正→再撮影→再判定)。
1. リアルに見える・超高品質: 形・寸法・素材の質感・経年・陰影・周辺の植生/地形/付帯物まで現実的。ベタ塗りの単色面・箱の連続・テクスチャ欠け・貫通/浮き・向きの誤りがない。
2. 他と明確に差別化: 平面形・駅舎・屋根・町並み・ポスター画像・象徴物が他駅/他区間と見て分かる。

## 判定票(駅・構造物・施設・車両・画像 共通)
| 項目 | 確認方法 | 不合格の例 |
|---|---|---|
| 形状・寸法 | 参照スペック(軌間1067・ホーム高・車両長/幅)と照合 | 寸法のずれ・比率の不自然 |
| 質感・経年 | 近接レンダ | 単色・のっぺり・過度に綺麗 |
| 向き | 数値検査(orient_check.py)+俯瞰 | 踏切/電柱/信号/建物正面が逆 |
| 周辺 | 俯瞰ZA/世界視点 | 地面が平坦・植生なし・地形が浮く |
| 差別化 | コンタクトシート | 同じ形の駅が並ぶ |
| 画像 | 可読性・実在標章なし・多様性 | 文字欠け・同一画風 |
| 室内 | 室内カメラ | 空洞・家具なし |
## 運用
- 群監査(大タスク完了時)と最終監査(超超超厳格)のみ。小タスクごとには行わない。
- 結果は net/status.json に正直に記録し、路線図 v2.1 に反映する。
## 構造物の追加基準
- 橋: アーチの開口・橋脚・高欄が側面から読める/川と高さが整合/橋台と築堤の取付。
- トンネル: 坑口の石積み・扁額・翼壁・切通しの取付、丘が地形として自然(単色の半球は不合格)。
- 踏切: 道路が線路に直交、遮断機・警報機が道路の両脇、踏板。

## 点数化(ユーザー指示 2026-10-12 14:43)
- 全監査は項目ごとに 0〜100 点を付け、理由を1行併記する。合否は従来どおり超厳格(「リアルに見える超高品質」かつ「他と明確に差別化」)。目安: 90点以上=合格候補(両条件を満たす)/70〜89=惜しいが不合格/50〜69=低品質/49以下=作り直し。
- 評価軸: ①リアルさ(形状・質感・汚れ・スケール) ②差別化(同種他形式/他駅と別物か) ③ディテール密度 ④内装(室内の作り込み・見える範囲・照明・小物・導線) ⑤整合(データ・路線図・運行系統と一致)。総合点=最低軸に引きずられる(最小値と平均の中間)。
- 内装の監査: 車両・駅舎・施設の室内を専用カメラ(窓越し/断面/内部視点)で3視点以上撮り、未確認は「未確認(0点扱いではなく要撮影)」と明記して推測で加点しない。

## 厳格化(ユーザー指示 2026-10-12 15:19)
- 合格=総合95点以上かつ全5軸90点以上。100点の基準は「実在写真と並べて見劣りしない」水準(ゲーム内CGの『よくできた模型』は70点止まり)。
- 減点を厳しく: 直方体の組み合わせ・球頭の人物・単色ベタ塗り・同一テンプレの色違い・繰り返しテクスチャの目立ち・スケール違和感・光の不自然さは各軸で大幅減点(各20点以上)。
- 未確認(見えていない・暗い・撮影不良)は0点扱い。推測で加点しない。
- 監査プロンプトに必ず含める: 「実在の写真と並べたとき見劣りする点を全て列挙し、各軸の点数を下げよ」。サブエージェントには前回点数を伏せ、甘い採点をしないよう指示する。

## 超超超厳格(ユーザー指示 2026-10-12 14:38・【X14】)
従来の「95点/90点」に加え、以下を**必須**とする。最終監査(X9)と車両・画像・駅の群監査で適用する。
1. **証拠の最低要件**: 1対象につき**8視点以上**(全景・前面3/4・側面・低位置・床下/足回り・屋根上・近接・車内通路[内装がある対象])。**人物『表示』と『非表示』の両方**(`PEOPLE_BOTH=1`)。足りない視点は「未確認=0点」。
2. **実車/実物との照合**: 対象の実在モデル(または参照仕様表 `net/vehicle_spec.md`)と、寸法・窓割・扉位置・前面形状・台車軸距(例: DT21=2,100mm・車輪径860mm)・屋根上機器を**数値で**照合し、ずれは「スケール/モデリング」軸で減点。
3. **減点上限(キャップ)**: 次のどれかが認められる軸は、その軸を**最大60点**とする — ①シルエットが箱・円柱の連続(面取りなし) ②単色ベタ面/同一テクスチャの繰り返しが目立つ ③人物がマネキン調 ④窓ガラスが単色(反射・縁・厚みなし) ⑤部品の浮き/接続切れ ⑥他形式と色違い程度の差。
4. **差別化は並置で判定**: 同種の対象(例: 気動車3形式、駅12駅)を**同一視点の並置シート**で比べ、「色を消しても別物と分かるか」を問う。色違いのみは差別化軸を最大50点。
5. **独立監査員は2名以上**(各自、前回点数を知らない新しい文脈)。**合格判定は低い方の点数**を採用し、2名の差が15点を超えたら画像の追加提出で再監査。
6. **自己採点の禁止と記録**: 点数・理由・使用した画像名を `net/status.json` と `net/session_state.md` に記録する。
7. **根拠のない加点の禁止**: 「おおむね良い」「改善した」は点数の根拠にならない(合否は絶対評価)。

## 部品単位の監査(X15 / 2026-10-12 ユーザー指示)
線路など1つ1つの部品も監査する。部品ごとに「近接3視点以上+数値検査+独立監査員の点数(軸別90以上・総合95以上)」。『未確認』は0点。

| 部品 | 数値検査(決定論) | 近接撮影で見る点(実写と並べて見劣りするか) |
|---|---|---|
| レール・枕木・バラスト | 軌間1,067 mm、枕木間隔、レール頭高さ=Z_RAIL、バラスト断面 | 継目板・犬釘・枕木の摩耗/木目、バラストの粒、錆の因果(頭は光る) |
| 分岐器・渡り線 | ノーズ位置、リード角、尖端/トング、連結の連続性(orient_graph) | 転轍機・トング・護輪軌条・バラストの乱れ |
| 踏切 | 道路/線路の向き(t/n)、遮断桿の長さと向き、警報機の高さ | 白黒縞・警報灯・床版・舗装の取り付き |
| 電柱・架線・碍子 | 架線高(5.0〜5.5 m)、柱間隔、ちょう架の接続 | 碍子・腕金・張力、錆・汚れ |
| 信号機・標識 | 向き、高さ、視認方向 | レンズ・庇・梯子・文字 |
| ホーム縁・白線・点字 | ホーム高(レール頭+0.83 m)、縁端〜車両限界 | 縁石の欠け、白線の摩耗、屋根・柱・梁の寸法 |
| 駅の部品(名標・ベンチ・時計・階段・跨線橋) | 寸法(ベンチ座面0.42 m、階段蹴上16〜18 cm) | 材質・経年・文字の可読性、他駅との差別化 |
| 車両の部品(台車・連結器・パンタ・前照灯・ドア・窓) | vehcheck(接地・幅・全長・台車数) | 台車の形式差、車輪径、連結器の高さ(880 mm)、窓の厚み/反射 |

採点は docs/audit_rubric.md の既存基準(上記の点数・上限 60 の条件を含む)に従う。撮影は `scripts/parts_audit.sh`(M04 の線路周り6視点。部品の種類を増やす際はここへ追記)。
