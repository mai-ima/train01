# 監査基準(audit_rubric.md) — 超高品質・差別化
合格は次の2条件を**両方**満たすときだけ。それ以外は不合格(修正→再撮影→再判定)。
1. リアルに見える・超高品質: 形・寸法・素材の質感・経年・陰影・周辺の植生/地形/付帯物まで現実的。ベタ塗りの単色面・箱の連続・テクスチャ欠け・貫通/浮き・向きの誤りがない。
2. 他と明確に差別化: 平面形・駅舎・屋根・町並み・ポスター画像・象徴物が他駅/他区間と見て分かる。

## 判定票(駅・構造物・施設・車両・画像 共通)
| 項目 | 確認方法 | 不合格の例 |
|---|---|---|
| 形状・寸法 | 参照スペック(軌間1067・ホーム高・車両長/幅)と照合 | 寸法のずれ・比率の不自然 |
| 質感・経年 | 近接レンダ | 単色・のっぺり・過度に綺麗 |
| 向き | 数値検査(orient_check.py)+俯瞰 | 踏切/電柱/信号/建物正面が逆 |
| 周辺 | 俯瞰ZA/世界視点 | 地面が平坦・植生なし・地形が浮く |
| 差別化 | コンタクトシート | 同じ形の駅が並ぶ |
| 画像 | 可読性・実在標章なし・多様性 | 文字欠け・同一画風 |
| 室内 | 室内カメラ | 空洞・家具なし |
## 運用
- 群監査(大タスク完了時)と最終監査(超超超厳格)のみ。小タスクごとには行わない。
- 結果は net/status.json に正直に記録し、路線図 v2.1 に反映する。
## 構造物の追加基準
- 橋: アーチの開口・橋脚・高欄が側面から読める/川と高さが整合/橋台と築堤の取付。
- トンネル: 坑口の石積み・扁額・翼壁・切通しの取付、丘が地形として自然(単色の半球は不合格)。
- 踏切: 道路が線路に直交、遮断機・警報機が道路の両脇、踏板。
