# C16 線路配置のリアル化(2026-10-17 ユーザー指示)

## 方針
実際の鉄道の配線に倣う: 曲線半径は設計速度に見合う大きさ、駅構内の分岐は分岐器の番数に応じた浅い角度、平行線の間隔は4.0〜4.5m以上、車止め・信号・転てつ機を伴う。

## 実施済み
- 新総合車両基地(穂波野): R200 の引き揚げ線 → 約12°のはしご線 → R150 の転向曲線 → 間隔4.5m の平行留置線12本。詳細は `docs/D4_DEPOT_LAYOUT.md`。
- `kit2.centerline`: 駅構内線の最小曲線半径を220mに自動制限(S字は振幅を縮小、緩和区間を延長)。駅内の辺の最小半径 38m → 167m(大半は229m以上)。
- 検査 `net/radius_check.py`: 各辺の最小曲線半径(12m等間隔化後)と設計速度の目安を照合して不足辺を列挙。

## 未了(C16 残件)
- 駅間の辺(幹線 SH04-SH05 R169 など26辺)の半径不足: 原因は kit4.hermite の端点条件(駅端の位置・向き)が隣駅と横ずれしていること。解消には `net/plan_geo` の駅座標/yaw の再配置と世界の再ビルドが必要。
- 駅ごとの配線(渡り線・安全側線・引上線)を `net/details.py` の線数に合わせて実在配線に倣い設計。
- 市電・地下鉄(速度0扱い)の半径下限の別判定。
