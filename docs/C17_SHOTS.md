# 【C17】駅間構造物の撮影手順(監査用・再現用)

作業側(/home/claude/station)で、変更した src ファイルをコピーしてから撮影する。
`WORLD_GRASS="x,y,半径"` を付けると世界合成(`--world bare`)でも近景に草の房が出る(付けないと地面が平坦な単色になる)。
`MULTICAM` の各視点は `x,y,z,tx,ty,tz,lens` を `;` で連結。出力は `out/c17m/<名前>_<n>.png`(1本あたり約5〜8分)。

実行例:
```
cd /home/claude/station && WORLD_GRASS="2745,855,60" MULTICAM="…" python3 main.py --world bare --w 800 --out c17m/shd40
```
注意: 古い日の同名画像を誤って見ないよう、撮影後は更新時刻(`ls -l --time-style`)を確認する。
`PROBE_RAY="x,y,z,dx,dy,dz;…" python3 main.py --world bare --no-render --w 100 --out junk` で、指定の光線が当たる物体名・材質を確認できる(約4分)。
