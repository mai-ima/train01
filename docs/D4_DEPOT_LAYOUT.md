# 穂波野 新総合車両基地の配線設計(D4/D5・C16)

ユーザー指示(2026-10-17): 線路の配置などもリアルにする。実際の車両基地の配線に倣う。

## 配線の考え方(実在の車両基地の一般的な配線を参考にした設計。特定の実在基地の複製ではない)
- **引き揚げ線**: 本線(第6線)の端から分岐し、緩い曲線(R=200m)で基地側へ。本線の運転を妨げず、列車が出入りする専用の線。
- **はしご線(ラダー)**: 引き揚げ線は斜め(約12°)の直線のはしご線に入り、各留置線がここから順に分岐する。留置線の平行間隔は4.5m。
- **分岐**: はしご線から各留置線への転向曲線は R=150m(約1:5相当の浅い分岐)。分岐器の転てつ機・先端レール・ノーズ・場内信号は `kit5.turnout` で配置。
- **台形の敷地**: 手前(本線側)の線ほど長く、奥の線ほど短い。端部は車止め(`trackkit.buffer_stop`)。
- **検修庫**: 手前の6線(第0〜5線)に大型庫(幅120m×奥行28m・高さ9.5m)。庫内にピット縁・作業歩廊・吊り照明・天井クレーン桁。
- **管理棟・技術開発棟**: はしご線の南側に配置(外形のみ。室内は D7/D8)。

## パラメータ(newdepot.py)
ALPHA=12°, LEAD_R=200, TURN_R=150, DY=4.5, N_STAB=12, X_END=480。

## 検査
- `net/radius_check.py`: 各辺の最小曲線半径と設計速度の整合(26辺が不足 → C16 で修正)。
- `net/orient_graph.py`: 接続角12°超0件。
