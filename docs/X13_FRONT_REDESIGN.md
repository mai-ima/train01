# 車両前面の作り直し設計(X13・2026-11-14)

## 背景
第1段階の車両審査(独立2名平均)は x13p 72.4 → x13q 74.75 → x13r 76.4 → x13t 74.25 で、約75で頭打ち(合格=総合80かつ全軸70)。
小さな付加部品(排障器・床下配管・灯具庇・帯)は点数に出なかった。共通指摘は一貫して次の4点:
1. 前面の大きなベタ面(emuA 橙/emuC 青/kiha 緑)
2. 台車まわりのスカート・排障器が灰色の箱
3. 屋根・床下機器の少なさ
4. 前面ガラスの単色反射と運転台の薄さ

## 試して効かなかったこと(再試行しない)
- 曲面ロフトの前面へ平板の帯・縦リブを後付け(x13u): 前面の内側に埋まり写らない。曲面に載せる部品は断面の外側へ出す必要がある。
- 窓ガラスの色・反射・埃の調整(x13p): 点数に出ず。
- 材質パラメータ(色・法線・周期)の調整全般。

## 方針: 前面の『断面』を変える
`_sec(w, zb, zt, rc)` は角丸の8点断面で、腰の段差(ベルトライン)を表現できない。
- 案A: 断面を12〜14点にして、腰の高さで幅を 0.04〜0.06m 絞る(窓下カウルと窓まわりの段差)。loft_x を使う全前面(round/slope/bonnet)に影響するため、1形式(kiha_exp)で確認してから展開する。
- 案B: 前面を『窓まわりの枠』と『下部カウル』の2つのロフトに分け、継ぎ目に 0.015m の段を作る(部品点数は増えるが断面関数は不変)。
- 推奨: 案B(影響範囲が局所的で、効果が撮影で確認しやすい)。

## 確認手順(1形式あたり)
1. kiha_exp のみで MULTICAM 3視点(正面・斜め・低位置)を撮る(約5分)。
2. 前面の段差が写っていることを目視で確認(写らなければ撤回)。
3. 4形式×8視点(x13 系・約45分)を撮り、独立2名で第1段階監査。平均が +3 以上なら採用、±3以内なら『効果未確認』として記録。

## 見積り
案B: 実装 約2時間(前面が round/slope/gate の3系統)+確認撮影 約1時間。
