# E5 全駅撮影の独立監査(strict-auditor へ渡すブリーフ)
対象: out/e5/sheets/*.jpg(作業側)→ リポジトリでは renders/work/e5/(コピー後)。視点別6枚(view0〜5)と駅別シート。
指示:
- docs/audit_rubric.md の基準で採点(軸別0〜100、合格=総合95以上かつ全軸90以上、未確認=0点)。前回点数は伏せる。
- 軸: リアルさ(質感・照明・スケール)/ 駅ごとの差別化(平面・駅舎・町・象徴物・構図の違い)/ 干渉・浮き・向き / 車両 / 人物・生活感 / 植生・地形。
- 『実在写真と並べて見劣りするか』を必ず問う。見劣りするなら理由を具体的に(例: 草の房が均一、樹冠が塊状、車両の影が弱い、ホーム端の質感)。
- 全駅のうち『他駅と見分けがつかない』駅の組を挙げる(視点別シートで同じ構図・同じ象徴物のもの)。
- 出力: 軸別点数表、致命欠陥トップ10(駅ID・視点・内容)、最優先の直し方3つ。ファイルは編集しない。
