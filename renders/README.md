# renders/ — 撮影(レンダ)画像
| フォルダ | 内容 |
|---|---|
| `deliver/` | 納品用(全駅俯瞰の montage。PNG) |
| `contact/` | 全駅コンタクトシート(同一視点で全駅。差別化の確認用) |
| `eye/` | 全駅の目線レンダ |
| `zones/` | 駅ゾーンの代表レンダ |
| `pano/` | パノラマ・特殊視点 |
| `routemap/` | 路線図ページ v2.4.5 の画面キャプチャ(PC/スマホ) |
| `work/vehicles/` | 車両の外観の撮影(形式別・前面/側面/床下・監査用シート) |
| `work/interiors/` | 車内の撮影(通路視点・座席・人物) |
| `work/stations/` | 駅・ゾーン・町の撮影(目線/俯瞰/検査) |
| `work/structures/` | 地下鉄・橋・トンネル・路面電車・世界視点などの構造物の撮影 |
| `work/misc/` | 分類できない作業画像 |
`work/` は作業過程(修正前後・検査・試作)。ファイル名の接頭辞は作業バッチ名(例 `za11_`=Z-A11、`fe1_`=外観確認1回目)。
